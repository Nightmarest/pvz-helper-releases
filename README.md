# Певезешка — Windows

Установщики и стабильный канал обновлений. Исходники здесь не публикуются.

[Скачать последнюю версию](https://github.com/Nightmarest/pvz-helper-releases/releases/latest)

Один установщик подходит для Windows x64 и ARM64. Обновления проверяются и скачиваются в программе; установка запускается через меню «Обновления → Установить и перезапустить».

Вход, пароли и настройки хранятся локально отдельно от программы. Требуются Windows 10/11 и доступ к Ozon.
